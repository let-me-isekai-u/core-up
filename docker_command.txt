# Docker Compose

## 3. Khởi động Docker services

> Docker Desktop phải được mở trước.

```bash
docker compose up -d
```

`-d` = chạy container ở background.

Kiểm tra:

```bash
docker compose ps
```

PostgreSQL hoạt động bình thường khi trạng thái là:

```text
Up ... (healthy)
```

---

## 4. Dừng Docker services

Dừng container nhưng không xóa:

```bash
docker compose stop
```

Chạy lại:

```bash
docker compose start
```

---

## 5. Restart

Restart toàn bộ services:

```bash
docker compose restart
```

Restart riêng PostgreSQL:

```bash
docker compose restart postgres
```

---

## 6. Down

Dừng và xóa container + network nhưng **GIỮ database volume**:

```bash
docker compose down
```

Dựng lại:

```bash
docker compose up -d
```

Routine reset container thường dùng:

```bash
docker compose down
docker compose up -d
```

---

# ⚠️ CẢNH BÁO

## 7. Xóa cả database volume

```bash
docker compose down -v
```

`-v` sẽ xóa Docker volume.

Với CoreUp, điều này có thể xóa toàn bộ database local:

```text
core-up_coreup_postgres_data
```

**Chỉ sử dụng khi thực sự muốn reset database từ đầu.**

# PostgreSQL

## 8. Truy cập PostgreSQL

```bash
docker exec -it coreup-postgres psql -U coreup_user -d coreup_db
```

Khi vào thành công:

```text
coreup_db=#
```

Kiểm tra version:

```sql
SELECT version();
```

Thoát:

```text
\q
```

---

## 9. Xem log PostgreSQL

```bash
docker compose logs postgres
```

Theo dõi realtime:

```bash
docker compose logs -f postgres
```

Hoặc:

```bash
docker logs -f coreup-postgres
```

Thoát chế độ follow:

```text
Ctrl + C
```

# Các lệnh quan trọng nhất cần nhớ

```bash
# Bật
docker compose up -d

# Kiểm tra
docker compose ps

# Restart
docker compose restart

# Dừng tạm
docker compose stop

# Chạy lại
docker compose start

# Xóa container nhưng giữ DB
docker compose down

# ⚠️ Xóa container + DB volume
docker compose down -v

# Log
docker compose logs -f

# Chạy backend với hot reload
dotnet watch --project src/CoreUp.Api
```

## Ghi nhớ nhanh

```text
up -d     = bật
ps        = xem trạng thái
stop      = dừng
start     = chạy lại
restart   = restart
down      = dọn container, giữ DB
down -v   = xóa cả DB local ⚠️
logs -f   = xem log realtime
dotnet watch = hot reload backend
```
